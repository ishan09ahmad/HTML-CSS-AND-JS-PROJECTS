#  Tic Tac Toe Game

A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.

##  Features

* Two-player gameplay
* Win & draw detection
* Restart game functionality
* Dark/Light mode toggle
* Responsive design

## 🛠 Tech Stack

* HTML
* CSS
* JavaScript
