# Contact Form

A responsive contact form built using HTML, CSS, and TypeScript with form validation, toast notification, and dark/light theme support.

## Features
- Form validation (name, email, message, consent)  
- Error handling with user feedback  
- Toast notification on successful submission  
- Dark/Light theme toggle (stored in localStorage)  
- Clean and responsive UI  

## Tech Stack
- HTML  
- CSS  
- TypeScript
