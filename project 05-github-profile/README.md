# GitHub Profile Finder

A responsive GitHub profile finder built using HTML, CSS, and TypeScript that fetches and displays user data using the GitHub API.

## Features
- Search GitHub users by username  
- Displays profile info (avatar, repos, followers, following)  
- Direct link to GitHub profile  
- Data persistence using localStorage  
- Delete/reset stored profile  
- Dark/Light theme toggle  
- Loading & error handling  

## Tech Stack
- HTML  
- CSS  
- TypeScript  
- GitHub API
