# Rock, Paper, Scissors Game

A responsive and interactive **Rock, Paper, Scissors** game built using HTML, CSS, and TypeScript. The game allows users to play against the computer with real-time score tracking and smooth UI transitions.

## Features
- Play Rock, Paper, Scissors against the computer  
- Randomized house (computer) selection  
- Live score tracking  
- Interactive UI with animations  
- Game result display (Win / Lose / Draw)  
- Reset / Play Again functionality  
- Rules modal popup  
- Fully responsive design  

## Tech Stack
- HTML  
- CSS  
- TypeScript  
- DOM Manipulation  

## Game Logic
- User selects Rock, Paper, or Scissors  
- Computer randomly selects a move  
- Winner is decided based on standard rules:
  - Rock beats Scissors  
  - Scissors beats Paper  
  - Paper beats Rock  
- Score updates dynamically based on result
