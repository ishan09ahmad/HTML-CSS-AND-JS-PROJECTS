# Where in the World?

A responsive countries explorer application built using HTML, Tailwind CSS, and TypeScript with country search, region filtering, detailed country pages, and dark/light theme support.

## Features
- Browse all countries with flag previews  
- Search countries in real time  
- Filter countries by region  
- View detailed country information  
- Navigate through border countries  
- Dark/Light theme toggle  
- Persistent theme using localStorage  
- Loading skeleton states  
- Error handling UI  
- Fully responsive design  

## Tech Stack
- HTML  
- Tailwind CSS  
- TypeScript  
- REST Countries API
