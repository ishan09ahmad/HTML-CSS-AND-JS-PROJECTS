# FAQ Accordion

A simple and responsive FAQ accordion built using HTML, CSS, and TypeScript.

## Features
- Expand/collapse FAQ items  
- Single & multiple open modes  
- Dark/Light theme toggle (saved in localStorage)  
- Clean and responsive UI  

## Tech Stack
- HTML  
- CSS  
- TypeScript
