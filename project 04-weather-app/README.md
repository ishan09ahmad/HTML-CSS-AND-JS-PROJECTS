# Weather App

A responsive weather application built using HTML, CSS, and TypeScript that fetches real-time weather data using an API.

## Features
- Search weather by city name  
- Displays temperature, humidity, and wind speed  
- Dynamic weather icons based on conditions  
- Error handling for invalid inputs  
- Clean and responsive UI  

## Tech Stack
- HTML  
- CSS  
- TypeScript  
- OpenWeather API
